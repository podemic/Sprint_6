# Sprint_6 

Проект по автоматизации тестов для сервиса Яндекс Самокат
https://qa-scooter.praktikum-services.ru/

Автотесты запускаются внутри браузера Mozilla Firefox 137.0.2
Фикстуры хранятся в файле conftest.py
Локаторы хранятся в директории locators
Тестовые данные для 2-ух юзеров хранятся в файле data.py
Тесты хранятся в директории tests
Файлы с классами для тестируемых страниц лежат в директории page_objects
test_logo_redirect - тесты переходов по клику на логотипы
test_main_page - проверки отображения правильного текста в блоке "Вопросы о важном"
test_order_page - проверка позитивного кейса оформления заказа самоката. проверка для 2 юзеров
Описание проекта в README.md
Отчет о тестировании в директории Allure, получить отчет в видео веб-страницы можно выполнив команду

"allure serve allure_results"
Зависимости в requirements.txt
Запуск всех тестов 
pytest -v

запуск allure 
pytest tests --alluredir=allure_results
allure serve allure_results
